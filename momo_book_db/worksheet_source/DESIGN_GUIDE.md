# 모모의 책장 학습지 — 디자인 가이드 & 자동 생성 규격

기준 샘플: `신화의숲 1차시 학습지 v2.dc.html` (겨울 고전분기 · LV 5 · A4 10장)
이 문서는 (1) 사람이 보는 디자인 규칙과 (2) 문항 DB로 교재를 자동 생성할 때 쓰는 규격을 함께 담는다.

---

## 1. 디자인 토큰

### 1.1 고정 색 (분기와 무관)
| 역할 | 값 | 쓰이는 곳 |
|---|---|---|
| ink | `#16150F` | 본문 글자 |
| paper | `#FFFDF7` | 답 쓰는 자리(표 칸·발췌문·자료 박스) |
| rule | `#C9C0AB` | 괘선 |
| ash | `#837E70` | 보조 글자(쪽수·라벨·푸터) |

> 분기가 바뀌어도 본문 색은 바꾸지 않는다. 흑백 복사에서 위계가 무너진다.

### 1.2 분기 색 (3색 세트)
| 분기 | main | sub | point |
|---|---|---|---|
| 겨울 · 고전 | `#1C2A39` | `#F5F2E7` | `#5A3E36` |
| 봄 · 탐구 | `#3F7A46` | `#FFF8E7` | `#E2703A` |
| 여름 · 문학 | `#0A6E92` | `#E8F8FF` | `#B8830F` |
| 가을 · 인문철학 | `#836B5D` | `#E8DCC3` | `#A8761F` |

보조: `main-2 = #31465C` (겨울 기준, main의 밝은 변형 — 안쪽 실선·괘선 테두리용), `gold = #C8A96A` (표지 전용 강조).

**역할 매핑**
- main → 페이지 외곽 띠(12mm), 표 머리, 문항 번호 도장, 독해유형 라벨 배경, 발췌문 좌측선, 글감 밴드
- sub → 페이지 내부 바탕
- point → 출처(p.xx), 예시 문구, 참고자료 머리, 그림 캡션 — **한 면에 4곳 이내**
- gold → 표지의 레벨/분기 줄, 헤어라인, 표지 이미지 테두리

### 1.3 서체
- 표지: `Gowun Batang` (제목·인용), 레벨·분기 줄만 `Noto Sans KR 700`
- 본문 제목·발췌문·표 머리: `Noto Serif KR`
- 지시문·문항·답란: `Noto Sans KR`
- 새 서체를 추가하지 않는다.

### 1.4 학년 톤 (색이 아니라 세 값으로만)
| 학년 | 본문 | 행간 | 괘선 높이 | 도장 |
|---|---|---|---|---|
| 초 3~4 | 15.5px | 1.85 | 8mm | 2.15em / −3° |
| 초 5~6 | 15px | 1.8 | 7.5mm | 2.05em / −2° |
| 중등 | 14.5px | 1.75 | 7mm | 1.95em / 0° |

샘플(LV5)은 초 5~6 톤: 괘선 `7.5mm`, 답란 배경은
`repeating-linear-gradient(to bottom, transparent 0, transparent calc(7.5mm - 1px), #C9C0AB calc(7.5mm - 1px), #C9C0AB 7.5mm)`.

## 2. 페이지 문법

### 2.1 판형과 프레임
- A4 세로, **고정 페이지 조판**(한 장 = 한 블록). 흘리는 조판은 쓰지 않는다 — 잘림·빈 페이지의 원인.
- 종이 → 흰 여백 `15mm` → **main 12mm 띠** → 내부 `sub` 바탕 → 내부 여백 `5mm 6mm 4mm`
- 본문은 종이 가장자리에서 약 32mm 안쪽 → 어떤 프린터에서도 안전.

### 2.2 페이지 구조 (모든 내지 공통)
```
[머리단]  로고(좌, 10mm)  ·············  STEP 0n + 단계명(우 정렬)
[가로선]  1px main → 2px main (이중선)
[상반부]  flex:1
[하반부]  flex:1   ← 상·하 2분할이 기본 골격 (PPT 전환 단위)
[푸터]   모모의 책장 · 독서논술   |  페이지 번호  |  도서 · 레벨
```
- 상·하반부는 각각 `flex:1; min-height:0`. 답란(`textarea`)에 `flex:1`을 주면 남는 높이를 답란이 흡수해 **페이지가 항상 꽉 찬다**.
- 페이지 번호는 표지 제외, 내지 1부터. 각 장에 직접 새긴다.

### 2.3 표지
전면 main 판. 위→아래: 로고(아이보리 단색) / gold 헤어라인 사이 `LV n · ○○분기` / 도서명(3.4rem) / 저자·출판사 / gold 점 구분선 / 표지 이미지(76mm, gold 테두리 + 아이보리 외곽선) / 인용 한 문장. 배경에 별자리 점 문양(불투명도 30~60%).
이름·날짜는 표지에 두지 않는다.

## 3. 문항 블록 유형 (반면 단위)

| 코드 | 구성 | 차지 |
|---|---|---|
| `excerpt` | 발췌문 박스 + 출처 | 상 또는 하 |
| `short` | 도장 번호 + 질문 + 괘선 답란 | 반면 |
| `figure` | 그림 + 캡션 (paper 바탕, main-2 테두리) | 반면 |
| `vocab-table` | 2열 표(단어·뜻 / 문장 만들기) 4행 | 반면 |
| `ox-list` | O·X 5문항, 원형 8mm | 반면 |
| `grid-table` | 3열 표 + 괘선 답칸 | 반면 |
| `reference` | 참고자료 박스(point 상단선) | 질문에 딸림 |
| `bg-quote` | 그림을 배경(불투명도 60%)으로 깔고 글 올림 | 반면 |

**배치 규칙**
1. 한 면 = 상반부 블록 1개 + 하반부 블록 1개.
2. `excerpt`는 그것을 근거로 하는 첫 문항과 같은 면에 둔다. 발췌문만 남기고 넘기지 않는다.
3. 그림이 있는 문항은 `figure`가 상반부, 질문+답란이 하반부.
4. 독해유형 라벨(`비판적`, `추론적`…)은 항상 블록 머리에 붙는다.
5. 빈 여백을 장식으로 채우지 않는다 — 답란 높이로 흡수한다.

## 4. 자동 생성 규격 (문항 DB → 교재)

### 4.1 입력 JSON
```json
{
  "meta": {
    "level": "LV5",
    "quarter": "winter-classic",
    "grade_tone": "elem-56",
    "session": 1,
    "book": { "title": "신화의 숲", "author": "김헌", "publisher": "포레스트북스",
              "cover_image": "assets/cover-sinhwa.jpg",
              "lead_quote": "신화는 거울처럼 우리를 비춰줄 거예요." }
  },
  "step1": {
    "vocab": [{ "word": "중재하다", "page": 59, "definition": "분쟁에 끼어들어 쌍방을 화해시키다." }],
    "ox":    [{ "statement": "…", "page": 38, "answer": "X" }]
  },
  "step2": [
    { "id": "q1", "types": ["비판적"], "excerpt": { "text": "…", "cite": "p.26" },
      "figure": null, "prompt": "…", "answer_kind": "short" },
    { "id": "q8-1", "types": ["적용적"], "figure": { "src": "assets/fig5-brands.png", "caption": "…" },
      "prompt": "…", "answer_kind": "grid-table",
      "table": { "columns": ["상표", "그리스·로마 신화", "의미"], "rows": [["판도라", "…", ""]] } }
  ],
  "step3": {
    "topic": "내가 만드는 별자리",
    "background_figure": "assets/fig4-constellation.png",
    "context": "…",
    "memos": ["…", "…"],
    "closing_note": "도입부만 적고, 완성한 글은 별도의 원고지에 이어서 씁니다."
  }
}
```

### 4.2 페이지 배정 알고리즘
```
pages = [cover]
pages += pack(step1.vocab → vocab-table, step1.ox → ox-list)      # 1장
for q in step2:                                                    # 반면 단위로 채움
    slots = []
    if q.excerpt: slots += [excerpt]
    if q.figure:  slots += [figure]
    slots += [answer_kind]
    place(slots, rule="한 면 2슬롯, 발췌문은 첫 문항과 동거")
pages += step3_page(topic band + bg-quote + memos + closing)        # 1장
renumber(pages, start_at=1, skip=cover)
```
- 슬롯이 남는 마지막 면은 `토론 메모`(자유 괘선)로 채운다 — 샘플 9페이지 방식.
- 한 차시 기준 산출: 표지 1 + 1단계 1 + 2단계 6~8 + 3단계 1 = **9~11장**.

### 4.3 검수 체크리스트 (생성 후 자동 검사)
- [ ] 모든 페이지에 머리단·푸터·페이지 번호가 있는가
- [ ] 한 면에 point 색 사용이 4곳 이하인가
- [ ] 답란 최소 높이 ≥ 괘선 2줄(15mm)인가
- [ ] 발췌문만 있고 질문이 없는 면이 없는가
- [ ] 그림이 원본 픽셀보다 확대되지 않았는가 (인쇄 150dpi 기준 폭 = mm × 5.9px)
- [ ] 텍스트가 페이지 박스를 넘지 않는가 (고정 조판이므로 넘치면 잘림)

### 4.4 이미지 규격
- 삽화: 최소 폭 900px 권장(A4 반면 150dpi). 샘플 삽화는 490×285px로 **확대 금지**.
- 표지: 3:4.2 비율, 최소 600×840px.
- 로고: `assets/logo-momo.png`(투명 배경, 내지용), `assets/logo-momo-ivory.png`(단색, 표지용).

## 5. 마무리 작업 순서 (권장)

1. **다운로드** — 프로젝트 전체를 내려받는다. 필요한 파일: `신화의숲 1차시 학습지 v2.dc.html`, `doc-page.js`, `support.js`, `assets/`, 이 문서.
2. **인쇄 확인** — 브라우저에서 파일을 열고 PDF로 저장해 실물 1부를 뽑아본다. 확인할 것: 12mm 띠의 잘림, 삽화 선명도, 괘선 간격이 학년에 맞는지.
3. **자산 교체** — 삽화 원본(낱장, 고해상도)이 있으면 `assets/fig1~5`를 같은 파일명으로 덮어쓴다. 코드 수정 없이 반영된다.
4. **분기 확장** — 4.1의 `quarter` 값만 바꾸고 1.2 표의 3색을 치환하면 봄·여름·가을 교재가 된다. 레이아웃은 그대로 쓴다.
5. **다음 차시** — 같은 파일을 복제해 내용만 교체하는 방식으로 2~12차시를 만든다(수동), 또는 4.2 알고리즘으로 생성기를 구현한다(자동).
6. **PPT 전환** — 각 페이지의 상·하반부가 슬라이드 1장에 대응한다. 내지 1장 = 슬라이드 2장이 기본 환산.

## 6. 하지 말 것

- 흘리는 조판으로 되돌리기 (잘림·빈 페이지 재발)
- 학년 구분을 색으로 표현하기
- 그림을 원본보다 크게 늘리기
- point 색을 본문에 쓰기
- 여백을 장식으로 채우기 — 답란 높이로 흡수
- 새 서체·새 색 추가
