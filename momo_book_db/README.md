# 모모의책장 교재DB

『모모의 책장』 교재 원본(학생용)에서 문항 데이터를 자동 추출해 구조화된 SQLite DB로 축적하는 파이프라인.

> aprolabs 저장소의 **독립 하위 폴더**로 동작한다. 기존 `nonsul_kb/`, `app/services/reading_essay/`와
> 코드·DB를 공유하지 않는다(완전히 새로 시작하기로 결정, 2026-08-26).

## 현재 단계: Phase 0 (골든 샘플)

- 골든 샘플 교재: 『나의 행복과 모두의 행복』(초등 5학년, 2026년 4분기, 10~11주차, 학생용)
- 입력 형식: **PDF** (이미 학생용 PDF가 원본 hwp와 함께 존재해서, hwp→docx/hwpx 변환 없이 PDF를 그대로 파싱 대상으로 결정)
- `golden_samples/`: 손으로 작성한 정답 JSON (파서 정확도 측정 기준)

## 스키마 승인 사항 (요청서 v1.1 대비 변경점)

- `discussion_qa`에 `order_label TEXT` 컬럼 추가 (승인됨, 2026-08-26)
  - 이유: 문항 번호에 `4-1`/`4-2` 같은 하위 번호가 있는데 `order_no`는 INTEGER라 이 값을 그대로 못 담음.
  - `order_no`는 앞자리 숫자만(4-1→4, 정렬/표시용), `order_label`은 원문 그대로("4-1", "4-2", 정답 파일 연결용 정확한 키).
- `reading_type`이 복수 태그인 경우(예: "적용적 / 비판적") 원문 순서와 무관하게 **정해진 우선순위로 정규화**해서 저장:
  `사실적 < 추론적 < 비판적 < 분석적 < 적용적` 순으로 정렬 후 `/`로 연결.
  예: "적용적 / 비판적" → `비판적/적용적` (원문에 "비판적 / 적용적"으로 나와도 동일하게 정규화됨)

## curriculum_id

서버 커리큘럼 DB(`app/models/momo_bookshelf.py`)의 `momo_bookshelf_weeks.id`를 참조한다
(주차 단위 정보가 있어야 하므로 `momo_required_books`가 아니라 `momo_bookshelf_weeks`를 씀).
