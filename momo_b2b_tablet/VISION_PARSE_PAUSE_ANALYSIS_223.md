## 2. 223건 전체 통계 비교 (신규 호출 없이 기존 데이터로 집계)

| 항목 | 방식 A | 방식 B |
|---|---:|---:|
| 총 항목 수(참고용 - 집계 범위 다름) | 1,648 | 4,077 |
| 제시문·질문 미분리(느슨한 휴리스틱) | 123 | 20 |
| 어순 뒤섞임(느슨한 휴리스틱) | 0 | 4 |
| 표/빈칸 구조 포착 | - | 1,715 |
| 쪽수 인용 있는 항목 | - | 1,970 |
| 쪽수 범위 이탈 의심 | - | 99 (5.0%) |

**"B 어순 뒤섞임=4"는 검증 결과 전부 휴리스틱 오탐이었다** - 4건 전부 **시
(詩) 인용문의 줄바꿈·들여쓰기**(정상적인 연 구분)를 정규식이 "공백 3개 이상"
으로 잘못 잡은 것이다(예: L5-Q3-W04 "해바라기 얼굴\n\n  누나의 얼굴은..." -
시 형식을 있는 그대로 보존한 것이지 어순이 깨진 게 아니다). **실제 어순
뒤섞임은 223건에서 0건** - 이전 실측(긴긴밤 문서)과 일관된다.

**"B 미분리=20"도 대부분 휴리스틱 오탐이다.** 20건 중 3건을 직접 열어보니:
- 2건은 질문이 짧은 인용부호/대괄호로 "시작"할 뿐(예: "‘세상에서 가장 못된
  아이’에서...") 실제로는 이미 완결된 짧은 질문 - 정규식이 문장 앞머리의
  홑따옴표만 보고 오판.
- 1건(`L3-Q1-W04`)은 자유 서술형 글쓰기 프롬프트가 원래 길어서(300자 이상)
  걸린 것으로, "제시문·질문이 안 갈라진" 문제가 아님.

**결론: 223건에서 방식 B가 실제로 악화시킨 사례는 확인되지 않았다.**
개선 사례(어순 정상화, 표/빈칸 구조 포착, 완전 실패 문서 복구)는 다수
확인됐고, 반증(악화 사례)은 이번 검증에서 발견되지 않았다 - 다만 1절의
"선잇기 매칭 구조 누락"은 **B가 A보다 못한 게 아니라(A도 애초에 안 잡음)
B도 아직 완전하지 않은 영역**으로 기록해 둔다.
