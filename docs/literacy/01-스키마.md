## 2. 절대 금지 사항

- 기존 수능 문제 DB 파일에 **어떤 경우에도 쓰기를 하지 않는다.** 읽을 일이 생기면 `zoom_reports/`의 `mode=ro` 분리 패턴을 사용한다.
- `main.py`를 제외한 **기존 라우터·에이전트·모델 파일을 수정하지 않는다.** 필요한 것은 전부 새 파일로 만든다.
- `main.py` 수정은 **라우터 import 2줄과 `include_router()` 2줄 추가까지만** 허용한다. 그 외 어떤 줄도 건드리지 않는다.
- 서버(`34.158.219.100`)에 SSH로 접속하지 않는다. 로컬 작업만 한다.
- **경로를 절대경로로 하드코딩하지 않는다.** `auto_qa_agent.py`가 `/home/chsh82/aprolabs/...`로 하드코딩되어 로컬에서 동작하지 않는 문제가 있다. 반드시 `auto_review.py` 방식의 `Path(__file__).resolve().parent` 기준 상대경로를 사용한다.

## 3. 파일 배치

새로 만들 파일은 다음과 같다. 기존 프로젝트의 디렉터리 관례와 충돌하면 관례를 우선하되, 결정한 경로를 작업 로그에 남긴다.

```
literacy/
├── __init__.py
├── db.py                  # literacy.db 전용 engine / SessionLocal / get_literacy_db
├── models.py              # SQLAlchemy ORM 모델
├── migrations/
│   └── 001_initial.py     # 초기 스키마 생성 스크립트
routers/
├── literacy_admin.py      # /literacy/*      (관리자용, 전역 인증 자동 적용)
└── literacy_api.py        # /api/literacy/*  (학생용, 추후 화이트리스트 예정)
raw/                       # API 원본 응답 보관 (이번 단계에서는 빈 디렉터리 + .gitkeep)
data/
└── literacy.db            # 생성될 DB 파일. .gitignore에 추가할 것
```

---

## 4. DB 연결 (`literacy/db.py`)

기존 웹앱의 SQLAlchemy 설정을 **재사용하지 말고 별도로 정의한다.** 기존 `get_db`를 건드리지 않는다.

- `literacy.db` 전용 `engine`과 `SessionLocal`을 새로 만든다
- FastAPI 의존성 함수 이름은 `get_literacy_db`
- DB 파일 경로는 상대경로 기준으로 계산한다
- SQLite 외래키 제약은 기본 비활성이므로, 연결 시 `PRAGMA foreign_keys=ON`을 켠다
- 배치 스크립트에서 ORM 없이 `sqlite3`로 직접 열 때 쓸 수 있도록, DB 파일 경로를 반환하는 `get_db_path()` 함수도 함께 제공한다

## 5. 스키마

### 5.1 `terms` — 표제어 통합 테이블

어휘·사자성어·속담·한자어·상식용어를 **한 테이블에 모은다.** 카테고리별로 테이블을 나누지 않는다.

| 필드 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `id` | INTEGER | PK, autoincrement | |
| `category` | TEXT | NOT NULL | `어휘` / `사자성어` / `속담` / `한자어` / `상식용어` |
| `headword` | TEXT | NOT NULL | 표제어 |
| `origin` | TEXT | | 원어(한자 등) |
| `definition` | TEXT | | 뜻풀이 |
| `pos` | TEXT | | 품사 |
| `sense_category` | TEXT | | krdict 의미 범주 |
| `subject_category` | TEXT | | krdict 주제 범주 |
| `grade_level` | INTEGER | | 학년 등급 1~12 (초1=1 … 고3=12) |
| `grade_source` | TEXT | NOT NULL, default `auto` | `auto` / `manual` |
| `source` | TEXT | NOT NULL | 출처 |
| `license` | TEXT | | 라이선스 |
| `external_id` | TEXT | | 원본 시스템 고유 ID (krdict `target_code` 등) |
| `collected_at` | DATETIME | NOT NULL | 수집 일시 |
| `updated_at` | DATETIME | | 최종 수정 일시 |
| `review_status` | TEXT | NOT NULL, default `검수전` | `검수전` / `검수완료` / `보류` / `제외` |
| `note` | TEXT | | 검수 메모 |

**제약 및 인덱스**

- `UNIQUE (source, external_id)` — 재수집 시 중복 방지의 핵심. 반드시 넣는다.
- 인덱스: `category`, `grade_level`, `review_status`, `sense_category`, `headword`

`grade_source`의 의미: 나중에 자동 등급 산정 기준을 보정해 전체를 재계산할 때, **`manual`인 행은 절대 덮어쓰지 않기 위한 플래그**다. 이후 단계의 모든 등급 갱신 로직은 이 값을 반드시 확인해야 한다.

## 6. 마이그레이션 스크립트 (`literacy/migrations/001_initial.py`)

요구사항:

1. **CLI로 단독 실행 가능해야 한다.** `python literacy/migrations/001_initial.py`
2. `data/literacy.db`가 없으면 생성하고, 위 6개 테이블·인덱스·제약을 만든다
3. **멱등성**: 이미 테이블이 있으면 아무것도 하지 않고 그 사실을 출력한다. 기존 데이터를 절대 지우지 않는다
4. `--drop` 플래그를 주면 테이블을 지우고 재생성한다. 단 실행 전 **`계속하려면 DROP을 입력하세요:` 확인 프롬프트**를 띄운다
5. 실행 결과로 생성된 테이블 목록과 각 테이블의 행 수를 출력한다
6. 경로는 전부 `Path(__file__).resolve().parent` 기준 상대경로

## 7. 라우터 스텁

이번 단계에서는 **동작 확인용 최소 엔드포인트만** 만든다. 검수 UI는 Phase 4에서 만든다.

- `routers/literacy_admin.py` — prefix `/literacy`, `GET /literacy/health` 하나만. `terms` 테이블 행 수를 JSON으로 반환
- `routers/literacy_api.py` — prefix `/api/literacy`, `GET /api/literacy/health` 하나만. `{"status": "ok"}` 반환

두 파일 모두 prefix는 기존 관례대로 **라우터 파일 안에서 스스로 정의**한다.
`main.py`에는 import와 `include_router()`만 추가한다.

학생용 라우터를 지금 분리해두는 이유는, 추후 momoai.kr에서 호출할 때 `/api/literacy/*`만 인증 화이트리스트에 넣기 위해서다. **지금 화이트리스트를 수정하지는 않는다.**
