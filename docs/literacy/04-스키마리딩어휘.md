## 같은 레벨 내 표제어 중복 — 42건 중 16건은 실제 동형이의어

학습 도구어 사전에서 같은 (레벨, 표제어) 조합이 여러 행에 걸쳐 나타나는 경우가 **42건** 있었다.

- **25건**: 한쪽은 뜻풀이가 비어 있고 다른 쪽만 채워짐 — 정보 손실 없음(빈 쪽은 같은 단어가 다른 주차에 재등장하되 뜻풀이를 다시 안 적은 것으로 보임).
- **1건**("의미")**: 두 행의 뜻풀이가 완전히 동일 — 단순 중복, 문제 없음.
- **16건**: **뜻풀이가 실제로 서로 다름 — 동형이의어**. 예를 들어 "긋다"는 한 행은 "비가 잠시 그치다"(날씨), 다른 행은 "금이나 줄을 그리다"(선을 긋다)로 완전히 다른 단어다. "쓰다"는 세 가지 다른 뜻(글씨를 쓰다/서류를 작성하다/모자를 쓰다)이 서로 다른 행에 나뉘어 있었다.

**Phase 3에서 승인받은 "동레벨 내 중복은 조용히 병합"(같은 내용이 다른 교재에 재등장하는 경우를 가정) 규칙은 이 자료에 맞지 않는다** — 여기서는 진짜로 다른 단어(동형이의어)가 우연히 같은 레벨, 같은 표제어 문자열로 겹친 것이기 때문이다. 그래서 이 16건은 버리지 않고, 기존에 있던 "`|`로 구분된 다의어 → 첫 번째만 `terms.definition`, 나머지는 `examples`" 처리 경로를 그대로 재사용해서 뜻풀이를 전부 보존하도록 바꿨다(`schemareading_parser.merge_same_level_duplicates()`).

## 대표 뜻풀이 수동 조정 — "긋다", "무리"

행번호가 가장 작은 쪽을 기본으로 대표를 삼았는데, 이게 "중요도 순서"라는 보장이 없어 사람이 직접 확인했다.

- **"긋다"(L1)**: 기본값(row61) "비가 잠시 그치다"가 대표로 뽑혔었는데, 사람이 확인한 결과 "금이나 줄을 그리다"(row63)가 더 대표적인 뜻이라 판단해 대표를 교체했다. "비가 그치다" 뜻풀이는 이제 `examples`로 보존된다.
- **"무리"(L1)**: 기본값(row136) "도리·이치에 맞지 않음 / 유리 연산 이외 관계"(수학 용어)가 대표로 뽑혔었는데, 초3~4(L1) 수준에서는 "사람·짐승·사물이 모여 뭉친 동아리"(row138)가 먼저 배우는 뜻이라 판단해 교체했다.

`schemareading_parser._MANUAL_PRIMARY_OVERRIDES`에 (레벨, 표제어) → 대표로 삼을 row_no를 하드코딩했다.

## 원본 데이터 오류 발견 — "삶"(L4), "정하다"(L1) 뜻풀이

- **"삶"(L4)**: 두 번째 행(row45) 뜻풀이가 "서로 관련을 가짐. 또는 그 관계."로 되어 있는데, 이건 명백히 "삶"의 뜻이 아니라 다른 단어("관련되다" 등)의 뜻풀이가 잘못 들어간 것이다.
- **"정하다"(L1)**: 두 번째 행(row353) 뜻풀이 "겉으로 보기에 비뚤어지거나 굽은 데가 없다. / 사리에 맞고 바르다."는 "정하다"가 아니라 **"곧다"**의 뜻풀이가 잘못 들어간 것으로 보인다.

둘 다 동형이의어가 아니라 **원본 스프레드시트의 데이터 오류**로 판단해, 해당 뜻풀이는 보존하지 않고 제외했다. `terms.note`에 "원본 데이터 오류로 제외된 뜻풀이 N건 있음"으로 남긴다. **원본 엑셀 파일은 수정하지 않았다.**

`schemareading_parser._KNOWN_BAD_DEFINITIONS`에 하드코딩되어 있다. **이 목록이 계속 늘어나면(현재 2건) 코드 밖(JSON/CSV 등 별도 파일)으로 분리하는 게 낫다** — 지금 규모에서는 하드코딩으로 충분하다고 판단했을 뿐, 관리 방식 자체를 고정한 건 아니다.
