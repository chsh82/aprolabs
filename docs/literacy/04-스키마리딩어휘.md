## 같은 레벨 내 표제어 중복 — 42건 중 16건은 실제 동형이의어

학습 도구어 사전에서 같은 (레벨, 표제어) 조합이 여러 행에 걸쳐 나타나는 경우가 **42건** 있었다.

- **25건**: 한쪽은 뜻풀이가 비어 있고 다른 쪽만 채워짐 — 정보 손실 없음(빈 쪽은 같은 단어가 다른 주차에 재등장하되 뜻풀이를 다시 안 적은 것으로 보임).
- **1건**("의미")**: 두 행의 뜻풀이가 완전히 동일 — 단순 중복, 문제 없음.
- **16건**: **뜻풀이가 실제로 서로 다름 — 동형이의어**. 예를 들어 "긋다"는 한 행은 "비가 잠시 그치다"(날씨), 다른 행은 "금이나 줄을 그리다"(선을 긋다)로 완전히 다른 단어다. "쓰다"는 세 가지 다른 뜻(글씨를 쓰다/서류를 작성하다/모자를 쓰다)이 서로 다른 행에 나뉘어 있었다.

**Phase 3에서 승인받은 "동레벨 내 중복은 조용히 병합"(같은 내용이 다른 교재에 재등장하는 경우를 가정) 규칙은 이 자료에 맞지 않는다** — 여기서는 진짜로 다른 단어(동형이의어)가 우연히 같은 레벨, 같은 표제어 문자열로 겹친 것이기 때문이다. 그래서 이 16건은 버리지 않고, 기존에 있던 "`|`로 구분된 다의어 → 첫 번째만 `terms.definition`, 나머지는 `examples`" 처리 경로를 그대로 재사용해서 뜻풀이를 전부 보존하도록 바꿨다(`schemareading_parser.merge_same_level_duplicates()`).

## 대표 뜻풀이 수동 조정 — "긋다", "무리"

행번호가 가장 작은 쪽을 기본으로 대표를 삼았는데, 이게 "중요도 순서"라는 보장이 없어 사람이 직접 확인했다.

- **"긋다"(L1)**: 기본값(row61) "비가 잠시 그치다"가 대표로 뽑혔었는데, 사람이 확인한 결과 "금이나 줄을 그리다"(row63)가 더 대표적인 뜻이라 판단해 대표를 교체했다. "비가 그치다" 뜻풀이는 이제 `examples`로 보존된다.
- **"무리"(L1)**: 기본값(row136) "도리·이치에 맞지 않음 / 유리 연산 이외 관계"(수학 용어)가 대표로 뽑혔었는데, 초3~4(L1) 수준에서는 "사람·짐승·사물이 모여 뭉친 동아리"(row138)가 먼저 배우는 뜻이라 판단해 교체했다.

`schemareading_parser._MANUAL_PRIMARY_OVERRIDES`에 (레벨, 표제어) → 대표로 삼을 row_no를 하드코딩했다.

## 원본 데이터 오류 발견 — "삶"(L4), "정하다"(L1) 뜻풀이

- **"삶"(L4)**: 두 번째 행(row45) 뜻풀이가 "서로 관련을 가짐. 또는 그 관계."로 되어 있는데, 이건 명백히 "삶"의 뜻이 아니라 다른 단어("관련되다" 등)의 뜻풀이가 잘못 들어간 것이다.
- **"정하다"(L1)**: 두 번째 행(row353) 뜻풀이 "겉으로 보기에 비뚤어지거나 굽은 데가 없다. / 사리에 맞고 바르다."는 "정하다"가 아니라 **"곧다"**의 뜻풀이가 잘못 들어간 것으로 보인다.

둘 다 동형이의어가 아니라 **원본 스프레드시트의 데이터 오류**로 판단해, 해당 뜻풀이는 보존하지 않고 제외했다. `terms.note`에 "원본 데이터 오류로 제외된 뜻풀이 N건 있음"으로 남긴다. **원본 엑셀 파일은 수정하지 않았다.**

`schemareading_parser._KNOWN_BAD_DEFINITIONS`에 하드코딩되어 있다. **이 목록이 계속 늘어나면(현재 2건) 코드 밖(JSON/CSV 등 별도 파일)으로 분리하는 게 낫다** — 지금 규모에서는 하드코딩으로 충분하다고 판단했을 뿐, 관리 방식 자체를 고정한 건 아니다.

## 레벨 0~6 체계와 학년 대응표

Phase 3에서는 `grade_level`(1~12, 학년 단위)을 기본 등급 기준으로 썼다. 그런데 이번에 확보한 두
자료(학습 도구어 사전, 스키마 어휘 목록)는 학년 단위가 아니라 **2개 학년을 묶은 단계 단위**로만
등급이 존재한다. 없는 정밀도를 있는 것처럼 저장하면 이후 등급 산정·문항 출제가 잘못된 정확도를
전제하게 되므로, `level`(0~6)을 새 기본 기준으로 도입했다.

| level | 학년 | grade_level 대응 |
|---|---|---|
| 0 | 초1~2 | 1, 2 |
| 1 | 초3~4 | 3, 4 |
| 2 | 초5~6 | 5, 6 |
| 3 | 중1~2 | 7, 8 |
| 4 | 중3 | 9 |
| 5 | 고1~2 | 10, 11 |
| 6 | 고3 | 12 |

`grade_level`은 삭제하지 않고 그대로 유지한다(`app/literacy/migrations/002_add_level.py`). 학년이
명확한 교재 어휘(`momo-textbook`, 821건)는 위 표대로 `level`을 백필했고 `grade_level`도 그대로
남아 있다. 속담·관용구(`krdict`, 2,884건)는 등급 정보 자체가 없어 `level`을 NULL로 둔다(이후 별도
단계에서 매긴다). 실제 운용 기준은 앞으로 `level`이다.

## Level4 시트 컬럼 불일치 등 파싱 시 주의점

- 헤더는 문서(`04-스키마리딩어휘적재.md`)가 설명한 3행째가 아니라 **실제로는 4행째**였다(3행째는
  `Level N`이라는 라벨 텍스트일 뿐). 4행을 헤더로 읽으니 문서가 경고한 "첫 행이 헤더로 중복되는
  문제" 자체가 발생하지 않았다.
- `Level4` 시트만 컬럼이 7개다. 다른 시트(`Level1/2/3/5/6`)는 유의어·반의어가 한 컬럼(6번째)에
  `(유)`/`(반)` 태그로 섞여 있는데, `Level4`는 유의어(6번째)·반의어(7번째) 컬럼이 분리돼 있다.
  `ws.max_column >= 7`로 분기했다(`iter_tooldict_entries()`).
- `(유)`/`(반)` 태그는 실제로 `Level3`에만 있다(116/146건). `Level1/2/5/6`은 태그가 전혀 없어
  방향을 알 수 없으므로 `tooldict-related`(방향 불명)로 저장한다.
- 표제어 뒤에 괄호가 붙은 9건을 발견해 처리했다: 괄호 안이 순수 한자면 한자 원어로 보고 `origin`
  으로 분리(`지(知)`→`지`+`知`, `내(內)`→`내`+`內`), 한자가 아니면 용법 예시로 보고 표제어에서
  떼어 `note`에 "용법: ..."로 기록(`긋다(밑줄을)`, `뽑다(카드를)`, `생활(방식)`, `세우다(식을)`).
- 같은 레벨 안에서 표제어가 중복되는 경우가 42건 있었고, 이 중 16건은 단순 중복이 아니라 실제
  동형이의어(뜻풀이가 서로 다름)였다. 자세한 내용은 위 "같은 레벨 내 표제어 중복" 절 참고.

## source 간 병합 금지 규칙과 이유

**서로 다른 `source` 사이에서는 절대 병합하지 않는다.** 같은 헤드워드 문자열이 서로 다른 source에
동시에 나타나는 경우 대부분이 실제로는 뜻이 다른 동형이의어이기 때문이다. 예를 들어 "교류"는
학습도구어에서 일상적 의미(예: "서로 사귀며 오고 감")이고 스키마 물리에서는 "교류 전기"다.
"위상"(일반적 위치·상태 / 물리 phase), "초점"(관심의 중심 / 광학 초점), "전자"(앞의 것 / 電子),
"지각"(느끼어 앎 / 地殼)도 마찬가지다. 병합하면 물리·과학 전문 용어가 초등 수준 어휘의 뜻으로
뒤섞이는 오류가 생긴다. `UNIQUE(source, external_id)` 제약이 이 분리를 보장하며, 파싱 단계에서
source를 넘어서는 임의 dedup은 하지 않았다.

실제로 헤드워드가 2개 이상 source에 겹치는 경우는 총 **66건**이며, 겹치는 source 조합별로 나누면:

- **tooldict ↔ schema (겹치는 두 자료만, 40건)**: 가치, 고려, 공존, 교환, 높낮이, 무게, 문화,
  발생, 부피, 분배, 분화, 생산, 소비, 수정, 시각, 시간, 신재생에너지, 에너지, 역할, 운동, 위상,
  위치, 잎, 자극, 저울, 전자, 정당, 정보, 정책, 조직, 줄기, 지각, 지진, 차례, 차별, 차이, 초점
  (37건) + 공동체·교류·문명(momo-textbook까지 3개 source 모두에 겹치는 3건)
- **momo-textbook ↔ tooldict (19건)**: 감각, 경과, 궁리, 규제, 대조, 도모, 맥락, 발달, 생략, 소재,
  시도, 양식, 우수, 인위적, 총괄, 토대, 통계, 통신, 획기적
- **momo-textbook ↔ schema (6건)**: 공약, 관습, 내전, 무역, 승화, 역차별
- **3개 source 모두(3건)**: 공동체, 교류, 문명
- **기타(1건)**: 어안이 벙벙하다 (krdict, momo-textbook)

이 중 6절 검증에서 직접 뜻풀이까지 대조한 5건(교류/위상/초점/전자/지각)은 모두 서로 다른 정의를
가진 별도 행으로 살아있음을 확인했다(교류는 3개 source에 각각 다른 정의로 존재).

**schema 자료 내부, 시트 간(사회/과학) 동일 헤드워드도 별도로 병합 금지 처리한 8건**이 있다
(발견은 Phase 3-2 작업 중, 문서 초안에는 없던 항목). `(sheet_key, headword)`로 그룹화해서 사회
스키마와 과학 스키마가 우연히 같은 단어를 쓰는 경우를 구분했다: 기단, 기압, 단층, 빅데이터, 시차,
이자, 조력에너지, 화산 활동. 예를 들어 "이자"는 사회 스키마에서는 금융 용어, 과학 스키마에서는
다른 뜻일 수 있어 시트 경계도 source 경계와 같은 방식으로 지켰다.

(같은 source, 같은 헤드워드가 **여러 레벨**에 반복 등장하는 "나선형 반복"은 이와 다르다 — 이건
병합 금지 대상이 아니라 최저 레벨로 병합하고 `note`에 전체 등장 레벨을 기록하는 대상이다. 교육
설계상 의도된 반복이기 때문이다.)

## 인문철학 스키마가 28건뿐인 이유

`인문철학스키마` 시트는 총 645행이지만 `단어명`이 채워진 유효 행은 **28행뿐**이다(나머지 617행은
헤드워드 칸이 비어 있음). 사용자 확인 결과 이는 오류가 아니라 **해당 스키마의 어휘 목록 작업이
아직 완료되지 않은 상태**이며, 추후 별도로 보강될 예정이다. 이번 단계에서는 빈 행을 억지로 채우지
않고 있는 28건만 그대로 적재했다(전부 `definition`까지 채워져 있어 채움률 100%).
