# 교재 DB 어휘 데이터 현황 (Phase 3 적재 전 조사)

- 대상 DB: `momo_book_db/momo_book.db` (SQLite, 별도 파일 — `aprolabs.db`/zoom_reports `momo_zoom.db`와 무관)
- 조사는 `mode=ro`(SQLite URI 읽기 전용) 커넥션으로만 수행. 실제로 쓰기 시도(`DELETE ... WHERE 1=0`)를 해서 `attempt to write a readonly database` 에러로 차단되는 것까지 확인함.
- 이 문서는 조사만 수행한 결과이며, 코드 작성·데이터 이동은 하지 않았음.

---

## 1. 스키마 — 어휘 데이터가 있는 위치

어휘 자체는 `vocabulary` 테이블에 있고, 레벨/분기/주차는 `vocabulary`가 아니라 **`documents` 테이블에 있다**(`vocabulary.doc_id`로 조인).

```sql
CREATE TABLE vocabulary (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    doc_id          TEXT NOT NULL REFERENCES documents(doc_id),
    order_no        INTEGER NOT NULL,
    word            TEXT NOT NULL,
    definition      TEXT,
    book_page       INTEGER,
    example_sentence TEXT,
    source_page     INTEGER,
    raw_text        TEXT,
    extraction_confidence REAL,
    review_status   TEXT DEFAULT 'pending'
)

CREATE TABLE documents (
    doc_id          TEXT PRIMARY KEY,   -- 예: L5-Q4-W10
    curriculum_id   TEXT,
    level           TEXT,               -- 'L1'~'L9'
    quarter         TEXT,               -- '1분기(고전)' 등
    week            INTEGER,            -- 1~13
    book_title      TEXT NOT NULL,
    book_author     TEXT,
    isbn            TEXT,
    source_file     TEXT NOT NULL,
    source_format   TEXT,
    source_hash     TEXT,
    version         INTEGER DEFAULT 1,
    parsed_at       TEXT,
    review_status   TEXT DEFAULT 'pending'
, cover_message TEXT, background_text TEXT)
```

`vocabulary`를 적재하려면 반드시 `documents`와 조인해야 레벨/분기/주차를 알 수 있다 — `vocabulary` 자체에는 그 정보가 없다.

같은 DB에 `discussion_qa`/`ox_quiz`/`essay_prompt`/`essay_outline_question`/`document_image`/`extraction_log` 테이블도 있지만 어휘와 무관해서 이번 조사 범위에 안 넣었다.

## 3. 레벨/분기/주차 필드 형식과 실제 값

`documents` 테이블 기준(조사 대상 DB 전체):

- `level`: 문자열 `'L1'` ~ `'L9'` (9단계, 접두사 L + 숫자)
- `quarter`: 한글 문자열 + 분기 테마가 괄호로 붙음 — 실제 고유값 4개:
  - `1분기(고전)`, `2분기(탐구)`, `3분기(문학)`, `4분기(인문예술)`
- `week`: 정수 `1` ~ `13`
- `doc_id`: `L{레벨}-Q{분기}-W{주차 2자리}` 형식(예: `L5-Q4-W10`)

`documents` 샘플 5행:
```
('L5-Q4-W10', 'L5', '4분기(인문예술)', 10, '나의 행복과 모두의 행복')
('L5-Q4-W11', 'L5', '4분기(인문예술)', 11, '나의 행복과 모두의 행복')
('L5-Q4-W01', 'L5', '4분기(인문예술)', 1, '두근두근 한국사 1권')
('L5-Q4-W02', 'L5', '4분기(인문예술)', 2, '두근두근 한국사 2권')
('L5-Q4-W03', 'L5', '4분기(인문예술)', 3, '두근두근 한국사 2권')
```

## 6. 표제어 형태 — 원형인지 활용형인지 (샘플 20개 원문)

`word` 필드는 **대체로 사전 기본형(원형)**이다 — 동사/형용사는 "-다"로 끝나는 기본형(예: "동요하다", "숭배하다", "분주하다"), 명사는 그대로("법률", "기색", "자초지종"). 활용된 형태(예: "동요했다", "숭배하며")는 샘플에서 발견되지 않았다.

다만 **`word` 필드에 헤드워드 외의 잡음이 섞여 있다** — 페이지 번호 주석이 줄바꿈과 함께 그대로 붙어 있는 경우가 흔하다:

```
('몰골\n(111쪽)', '볼품없는 모양새.')
('법률', None)
('성글다', '물건의 사이가 뜨다.')
('기색', '• 마음의 작용으로 얼굴에 드러나는 빛.\n• 어떠한 행동이나 현상 따위가 일어나는 것을 짐작할 수 있게\n하여 주는 눈치나 낌새')
('동요하다\n(150쪽)', '생각이나 처지가 확고하지 못하고 흔들리다.')
('자초지종', '처음부터 끝까지의 과정.')
('들볶다', '까다롭게 굴거나 잔소리를 하거나 하여 남을 못살게 굴다.')
('희귀하다\n(14쪽)', '드물어서 특이하거나 매우 귀하다.')
('부과하다', '세금이나 부담금 따위를 매기어 부담하게 하다.')
('으뜸', None)
('숭배하다\n(22쪽)', '우러러 .공경하다')
('성화(成火)', '일 따위가 뜻대로 되지 아니하여 답답하고 애가 탐. 또는 그런 증세.')
('맞추다', None)
('호의호식', '좋은 옷을 입고 좋은 음식을 먹음.')
('보살피다', None)
('선율\n(174쪽)', '소리의 높낮이가 길이나 리듬과 어울려 나타나는 음의 흐름.(멜로디)')
('나약하다', None)
('기꺼이', None)
('분주하다', '몹시 바쁘게 뛰어다니다.')
('홀로', None)
```

정리하면 `word`에 나타나는 잡음 패턴 3가지:
1. `표제어\n(NN쪽)` — 페이지 번호 주석(가장 흔함)
2. `표제어(한자)` — 한자 병기(예: `성화(成火)`)
3. 위 둘이 겹치는 경우(예: `실의(失意)\n(176쪽)`)

7절에서 이 잡음을 제거한 뒤 매칭했더니 매칭률이 크게 올라간 것으로 보아, Phase 3 적재 시 이 정제 로직이 필요하다.

## 7. krdict 덤프 존재 비율 (샘플 100개 추정)

`vocabulary`의 고유 단어 881개 중 100개를 무작위 추출(`random.seed(42)`)해서, Phase 2에서 이미 받아둔 krdict 전체 덤프(`raw/krdict/krdict_dump/`, 51,909개 표제어 — 단어 47,006 + 구/관용구/속담/문법·표현)에 단순 문자열 일치로 존재하는지 확인.

| 매칭 방식 | 매칭 건수 |
|---|---|
| `word` 원문 그대로 | 77 / 100 (77%) |
| 6절의 잡음(페이지 주석·한자) 제거 후, krdict 전체 카테고리 대상 | **88 / 100 (88%)** |
| 잡음 제거 후, krdict "단어" 카테고리만 대상 | 88 / 100 (88%) — 위와 동일(전부 "단어" 카테고리에서 매칭됨) |

**즉 잡음만 제거하면 원문 그대로보다 11%p 올라간다** — 6절에서 발견한 페이지 주석/한자 병기가 매칭을 방해하고 있었다는 게 정량적으로 확인됨.

매칭 안 된 12건 중 확인한 원인:
- **OCR/추출 오류로 깨진 표제어**: `ㅍㄹㅋㄹㅅㅌㅅ기법`, `ㅋㅅㄷㄹ 증후군`(자모가 깨진 상태로 저장됨)
- **정의/문장이 word 컬럼에 잘못 들어간 행**: `의기양양하여 뽐내다.`, `말과 행동으로 위협하는 짓.`, `깎아지른 듯한 언덕.` — 이건 표제어가 아니라 뜻풀이 문장 자체가 `word`에 들어간 데이터 오류로 보인다(추출 파이프라인 버그로 word/definition이 어긋난 사례일 가능성)
- **복합 표현**: `산술 평균`(공백 포함 복합어, krdict에 다른 형태로 등재됐거나 없을 수 있음)
- **정상 단어인데 krdict에 없는 경우**: `아퀴`, `승강이`, `데면데면` — 이런 경우는 실제로 krdict에 없는 것으로 보임(재확인은 안 함)
- **페이지 주석 형식이 깨진 경우**: `아연실색\n(페150이지)`(순서가 뒤바뀐 오탈자라 정규식 정제로도 못 잡음), `현혹시키다\n(p.293)`(정제 로직에서 영문 페이지 표기 패턴을 못 잡아서 놓침 — 정규식 보강 여지 있음)

**요약: 표제어 잡음을 제거하면 교재 어휘의 약 88%가 krdict 덤프에 이미 존재한다.** 나머지 12%는 OCR 오류/데이터 오류/정규식 미비/실제 미등재가 섞여 있어, Phase 3에서 krdict 매칭으로 뜻풀이를 보강하려면 이 잡음 제거 로직과, 매칭 안 되는 나머지에 대한 처리 방침(그대로 둘지, 수동 검수로 넘길지)이 필요하다.

## 발견된 교재DB 데이터 오류 (Phase 3 적재 중 확인, 교재DB는 고치지 않음 — 기록만)

**`vocabulary.id` 637~676 (40건, 전부 L1) — word/definition 컬럼이 통째로 뒤바뀜.**
개별 오류가 아니라 이 40건이 연속된 id 블록 전체에 걸쳐 있어, 특정 책/주차를
추출할 때 파이프라인이 두 컬럼을 통째로 바꿔 넣은 것으로 보인다. 예:
`word='의기양양하여 뽐내다.'`, `word='말과 행동으로 위협하는 짓.'`,
`word='깎아지른 듯한 언덕.'` — 전부 `word`에 뜻풀이 문장이, (추정상) `definition`
쪽에 원래 표제어가 들어가 있을 가능성이 높다. **교재DB 쪽에서 이 40건의
word/definition을 바로잡으면, Phase 3에서 재적재 시 L1 어휘 40건을 그대로
복구할 수 있다.** Phase 3는 이 40건을 적재하지 않고 `unmatched.csv`에
`컬럼의심`으로만 기록해 사람 검수로 넘긴다.

**OCR 손상으로 보이는 표제어**: `ㅍㄹㅋㄹㅅㅌㅅ기법`, `ㅋㅅㄷㄹ 증후군` — 자모가
깨진 상태로 저장돼 있어 정제로 복구 불가능(7절에서 이미 확인).

**`example_sentence` 전체 공란**: 939건 전부 NULL/빈 문자열(5절).

**`definition` 누락 비율**: 939건 중 386건(41.1%) 비어 있음(5절 — 553건만 채워짐).

**`subject_category` 참고**(krdict 매칭 후 기준, Phase 3 dry-run에서 확인): 매칭된
항목의 약 17%만 `subject_category`가 채워져 있음. 향후 퀴즈 오답 생성 등에서
이 필드에 크게 의존하는 설계는 피하고 `sense_category`(채움률 95%대)를
기준으로 잡는 게 안전하다.
