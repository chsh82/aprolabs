# Phase 3 — 교재 어휘 정제 및 적재

## 0. 시작 전에

`docs/literacy/00-현황.md`, `01-스키마.md`, `03-교재어휘-현황.md`를 먼저 읽어라.
작업 브랜치는 `literacy-db`다.

---

## 1. 목적

교재DB(`momo_book_db/momo_book.db`)의 어휘 881개를 정제해 `literacy.db`의 `terms`에 적재한다.

이 어휘들의 가치는 **양이 아니라 등급의 신뢰도**에 있다. 실제 학생이 해당 레벨에서 읽은 단어이므로, 앞으로 사전 어휘 수만 건의 학년 등급을 추정할 때 **정답지(gold standard)** 로 쓰인다. 그러니 양을 늘리는 것보다 **한 건 한 건이 정확한 것**이 훨씬 중요하다.

---

## 2. 절대 금지 사항

- **교재DB는 `mode=ro` 읽기 전용으로만 연다.** 어떤 경우에도 쓰기를 시도하지 않는다
- **교재DB의 데이터 오류를 고치지 않는다.** 발견하면 기록만 하고 원본은 그대로 둔다
- 기존 라우터·에이전트·모델 파일을 수정하지 않는다
- `app/literacy/models.py`의 스키마를 변경하지 않는다. 부족하면 **고치지 말고 보고하라**
- 서버(`34.158.219.100`)에 접속하지 않는다
- 절대경로 하드코딩 금지
- 사전(krdict) 전체 어휘 5만 건을 적재하지 마라. **이번 범위는 교재 어휘뿐이다**
- 검수 UI, 퀴즈 생성 코드를 만들지 마라

## 4. 레벨 → 학년 매핑

교재 레벨은 초1~중3에 그대로 대응한다.

| level | grade_level | 학년 |
|---|---|---|
| L1 | 1 | 초1 |
| L2 | 2 | 초2 |
| L3 | 3 | 초3 |
| L4 | 4 | 초4 |
| L5 | 5 | 초5 |
| L6 | 6 | 초6 |
| L7 | 7 | 중1 |
| L8 | 8 | 중2 |
| L9 | 9 | 중3 |

`grade_source`는 **`manual`** 로 저장한다. 자동 추정이 아니라 실제 교재 편성에 근거한 값이므로, 이후 어떤 자동 등급 산정 로직도 이 행들을 덮어써서는 안 된다.

**같은 단어가 여러 레벨에 등장하면 가장 낮은 레벨을 채택한다.** (처음 배우는 시점이 그 단어의 난이도다.) 이 경우 `note`에 다른 등장 레벨을 기록한다. 예: `L3,L5 중복 등장`

---

## 5. 표제어 정제 (`normalize.py`)

`vocabulary.word`에 잡음이 섞여 있다. 아래 순서로 정제한다.

1. 페이지 주석 제거 — `(111쪽)`, `(11쪽)` 등 `(숫자쪽)` 패턴
2. 한자 병기 분리 — `(成火)` 같은 괄호 안 한자는 제거하되, **버리지 말고 `terms.origin`에 저장**한다
3. 앞뒤 공백·개행 제거
4. 그 밖의 괄호 주석은 **제거하지 말고 그대로 두고 로그에 남긴다.** 어떤 패턴이 더 있는지 파악해야 하므로 임의로 지우지 마라

**정제 전 원문은 반드시 보존한다.** `terms.note`에 `원문: <정제 전 문자열>` 형태로 남긴다. 정제 로직이 잘못됐을 때 되돌릴 수 있어야 한다.

### 컬럼 뒤바뀜 처리

`word`와 `definition`이 뒤바뀐 행이 최소 3건 확인됐다. 자동 판별을 시도하되 **임의로 교정하지 마라.**

의심 기준(예시): `word` 길이가 비정상적으로 길거나 문장부호로 끝나는 경우.

의심되는 행은 적재에서 **제외**하고 `data/literacy/unmatched.csv`에 사유 `컬럼의심`으로 기록한다. 판단은 사람이 한다.

## 6. 사전 매칭

정제된 표제어를 krdict 덤프에서 찾아 정보를 보강한다. 덤프는 `raw/krdict/`에 이미 있다.

매칭 성공 시 채울 필드:

| 필드 | 출처 |
|---|---|
| `definition` | krdict 뜻풀이. **단, 교재DB에 definition이 있으면 교재 것을 우선한다** |
| `pos` | krdict 품사 |
| `origin` | 원어(한자 등). 정제 단계에서 얻은 한자가 있으면 그것을 우선 |
| `sense_category` | krdict 의미 범주 |
| `subject_category` | krdict 주제 범주 |

교재 뜻풀이를 우선하는 이유: 학생 눈높이에 맞춰 쓰인 문장이라 사전 정의보다 교육적으로 낫다. 다만 교재 뜻풀이가 있어도 **krdict 뜻풀이는 `examples`에 `source='krdict-definition'`으로 함께 저장**한다. 나중에 비교할 수 있어야 한다.

`sense_category`는 반드시 채워라. **퀴즈 오답 생성이 이 필드에 의존한다.**

### 매칭 실패 시

- `terms`에는 **적재한다.** 교재에 실린 단어라는 사실 자체가 중요하다
- 사전 정보 필드는 NULL로 두고, `review_status='보류'`로 저장한다
- `data/literacy/unmatched.csv`에 `단어 / 레벨 / 원문 / 실패사유` 를 기록한다

---

## 7. terms 저장값

| 필드 | 값 |
|---|---|
| `category` | `어휘` |
| `headword` | 정제된 표제어 |
| `source` | `momo-textbook` |
| `license` | `자체제작` |
| `external_id` | `vocabulary` 테이블의 PK |
| `grade_level` | 4절 매핑 |
| `grade_source` | `manual` |
| `review_status` | 매칭 성공 `검수전` / 실패 `보류` |
| `collected_at` | 현재 시각 |
| `note` | 원문, 중복 레벨 등 |

`UNIQUE(source, external_id)`가 걸려 있으므로 `INSERT OR IGNORE`를 쓴다. **재실행해도 행 수가 늘지 않아야 한다.**

`collection_runs`에 이력을 남긴다. `source='momo-textbook'`. try/finally로 반드시 마감한다.

## 9. 검증

1. `terms`에서 `source='momo-textbook'` 행 수 보고. 고유 단어 881개 기준으로 대조하고, **차이가 있으면 그 원인을 설명하라** (중복 병합, 컬럼 의심 제외 등)
2. `grade_level`별 분포 출력. L1~L6에 값이 있고 L7·L9이 0인지 확인
3. `grade_source='manual'` 행 수가 적재 건수와 일치하는지 확인
4. `sense_category`가 채워진 비율 보고
5. **재실행 후 행 수 증가 없음** 확인
6. 무작위 10건의 `headword` / `definition` / `grade_level` / `note` 전문 출력
7. `unmatched.csv` 행 수와 상위 20건 출력
8. **교재DB가 변경되지 않았는지 확인** — 파일 수정시각과 `vocabulary` 행 수(939) 대조
9. `/literacy/health`의 `terms_count` 확인 (속담·관용구 2,884 + 이번 적재분)
10. `git status`
