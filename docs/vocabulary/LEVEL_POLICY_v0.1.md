# Vocabulary Level Policy v0.1

## 공식 학년 체계

| 레벨 | 대상 학년 | 코드 |
|---:|---|---|
| L0 | 초등 1~2학년 | E1_2 |
| L1 | 초등 3~4학년 | E3_4 |
| L2 | 초등 5~6학년 | E5_6 |
| L3 | 중학교 1~2학년 | M1_2 |
| L4 | 중학교 3학년 | M3 |
| L5 | 고등학교 1학년 | H1 |
| L6 | 고등학교 2~3학년 | H2_3 |

레벨은 학생의 현재 학년이 아니라 해당 의미의 어휘를 본격적으로 학습·사용할 목표 학년군을 뜻한다.

## 원천 등급과의 연결

현재 5,723개는 김광해 계열의 국어교육용 어휘 등급 중 2~4등급을 포함한다.

- 원천 2등급: 정규교육 이전 습득 어휘 → L0 중심
- 원천 3등급: 초등교육 단계 습득 어휘 → L1~L2
- 원천 4등급: 사춘기 이후·중등교육 단계 어휘 → L3~L4
- L5~L6: 현재 원천 범위 밖이며 고등 어휘 자료 확장 후 배정

원천 등급은 학년군과 일대일로 같지 않으므로, 전문 분야 여부·학생용 뜻풀이 길이·추상 개념 표지·표제어 길이 등을 보조 특징으로 사용한다.

## 상태와 사용 제한

- `PROVISIONAL_AUTO`: 자동 후보이며 학생 공개 불가
- `REVIEW_BOUNDARY`: 인접 레벨 경계에 있어 재판정 필요
- `level_version=level_policy_v0.1`
- 기존 원본 콘텐츠와 문항에는 레벨을 직접 덮어쓰지 않는다.
- 자동 후보를 DB에 적재할 때도 별도 레벨 테이블 또는 신규 nullable 필드로 관리한다.

## 현재 데이터의 한계

현재 원천에는 5등급 이상 어휘가 없으므로 L5·L6을 억지로 채우지 않는다. 7단계 스키마는 유지하되 빈 레벨은 데이터 범위의 공백으로 기록한다.

## 십자말 판정

세트별 10개 어휘의 평균·중앙값·최솟값·최댓값과 레벨 폭을 계산한다.

- 폭 0~2: `LEVEL_COHERENT`
- 폭 3: `MIXED_REVIEW`
- 폭 4 이상: `REBUILD_RECOMMENDED`

현재 십자말은 레벨을 고려하지 않고 만든 파일럿이므로 분석만 수행하고 자동 재배치는 다음 버전에서 진행한다.
