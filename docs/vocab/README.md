# 문해력 게임 프로토타입

모모의 책장 어휘·사자성어 학습 게임. 전부 단일 HTML이며 의존성이 없다. 파일을 브라우저로 열면 그대로 돈다.

## 구성

```
db/idiom_schema.sql        사자성어 학습 DB 스키마 (SQLite)
games/idiom/               사자성어 단품 게임 5종
games/voyage/              80일간의 어휘 일주 (지도 + 구간 6종)
docs/quiz-api.md           문항 공급 API 계약
HANDOFF.md                 개발 이관 명령서 ← 먼저 읽을 것
```

## games/idiom — 사자성어 단품

| 파일 | 이름 | 훈련하는 것 | 조작 |
|---|---|---|---|
| archery.html | 성어 활쏘기 | 상황에서 성어 떠올리기 | 조준 |
| snake.html | 성어 붓길 | 한자 구성과 순서 | 방향 이동 |
| judge.html | 성어 감별소 | 문장 속 바른 쓰임 | 좌우 판정 |
| runner.html | 먹줄 달리기 | 뜻에서 구성 글자 인출 | 점프·숙이기 |
| nautilus.html | 노틸러스 탐사 | 순서 포함 인출 | 이동해서 잡기 |

## games/voyage — 80일간의 어휘 일주

`map.html` 이 뼈대다. 실제 위도·경도에 투영한 세계지도 위로 포그가 항로를 따라 이동하고, 80일 예산에서 오답마다 하루씩 깎인다. 마지막에 날짜변경선 반전이 나온다.

| 파일 | 구간 | 어휘 종류 | 조작 |
|---|---|---|---|
| suez.html | 수에즈 운하 | 배경지식(지리) | 연속 조향 |
| elephant.html | 인도 정글 | 속담·성어 | 3레인 달리기 |
| hongkong.html | 홍콩 부두 | 조합형 | 끌어다 놓기 |
| pacific.html | 태평양 폭풍우 | 교과학습어휘 | 갑판 균형 |
| train.html | 대륙 횡단 열차 | 문맥 속 낱말 | 조준 |
| furnace.html | 대서양 화로실 | 복습 | 병행 작업 |

일곱 파일 모두 왼쪽 상단에 회중시계가 있어 실제 걸린 시간을 잰다.

`furnace.html` 은 두 모드다. 기본은 앞 구간에서 틀린 문항을 태우는 복습이고, 틀린 게 없으면 어휘 판단 없이 콤보와 기록 경신만 겨루는 전속 항해로 갈라진다.

## 현재 상태

- 문항은 전부 각 파일에 하드코딩. 서버 연동은 아직이다.
- 게임끼리 연결되어 있지 않다. 각각 독립 실행된다.
- 학습 기록을 저장하지 않는다.
- 수업 검증 전이다.
