직전 보고서(`nikl_official_vocab_matching_20260929.md`)의 모든 소계를 원본
행 단위(`nikl_official_match_full_20260929.csv`, 5,950행)에서 독립적으로
다시 계산했다. 세 개의 산출물(`nikl_official_match_full`,
`l0l6_level_classification_full_CORRECTED`, `l0l6_level_vs_db_comparison_
CORRECTED`)이 정확히 동일한 5,950개 `content_id` 집합을 갖고 있음을
확인했고(양방향 차집합 0), `매칭_카테고리`/`공식_대조_결과`/`227건`/

0(교집합)으로 정확히 재현됐다 — **CSV 자체에는 행 손실이나 분모 오류가
없었다.**

**실제로 발견해 고친 것 1건(사용자가 지목한 "4건"과 정확히 같은 수는
아니지만, 철저한 재검증으로 찾아낸 유일한 실제 누락)**: §4의 서술("1,855건
+ 91건 + 50건")이 1,997건 중 1,996건만 설명하고 있었다 — 나머지 1건
(`SC_V192_B002_030`, "고등학교", 이미 재검증 단계에서 확인된 유일한 명시적
`CONFLICT` 사례)은 내부(김광해) 변환등급이 이미 `L0`이라, "경계(L3~L4)/
경계(L1~L2)/제외(수동배치)" 세 범주 서술에 들어가지 못하고 빠졌다. 이번
정정본에서는 아래처럼 네 번째 범주("L0")를 명시해 1,855+91+50+**1**=1,997로
전부 설명한다.

또한 §6("210+2,004=2,182")의 계산도 중간 단계(교집합 32건)를 보여주지
않고 결과만 제시했었다 — 이번에 직접 재계산해 `210 + 2,004 − 32(교집합) =
2,182`임을 명시적으로 확인했다(교집합 32건은 대부분 227건 배치·78건
뜻풀이위험 세트와 공식대조 충돌이 겹치는 항목).

**투명성 참고**: 사용자가 말한 "4건"을 정확히 특정하는 다른 근거를 찾지
못했다 — 위 1건짜리 서술 누락 외에는, 검증 가능한 모든 표의 합계가
정확했다. 더 구체적으로 지목하실 부분이 있으면 이 스크립트로 즉시
재확인 가능하다.

## 5. 일괄 적용 규칙안 — 표본 검수 결과

**RULE_A**: `official_grade==4 ∧ current_vocab_level==3` → `proposed_base_level=L2`
(1,368건). 표본 15건(seed=42) 실사: 해지다·낙담하다·거짓말투성이·불균형하다·
백분율·물장난하다·달그락달그락·짜개다·금메달리스트·탈퇴하다·예술제·겨를·
게시되다·기세등등하다 등 — 전부 초등 5~6학년(L2) 수준으로 보기에 무리가
없고, 현재 DB(L3=중1~2)와 딱 1레벨 차이라 재검증 보고서의
`DB_OVERCONFIDENT_BOUNDARY` 가설과 정확히 부합한다. **일괄 적용 후보로
안전 판단.**

**RULE_B**: `official_grade==3 ∧ current_vocab_level==2` → `proposed_base_level=L1`
(40건). 표본 15건 실사: 아지랑이·안전띠·케첩·몰라주다·하기야·실망스럽다·
제작되다·후덥지근하다·중얼중얼·요만하다·빨래집게·적응력·조심성·거칠어지다·
자유스럽다 등 — 전부 초등 3~4학년(L1) 수준으로 무리 없음. Rule A와 같은
성격의 1레벨 차이. **일괄 적용 후보로 안전 판단.**

**규칙 미적용/제외(레벨격차과대 35건)로 판정한 근거**: 나머지 조합
(예: 4등급×L4~L6, 2등급×L6 등, 2단계 이상 차이)을 전수 검토한 결과 —
`특별법·자아·타당성·탈피·궁극·객관적·논하다·실질·심층·언급`(4등급×L6,
11건), `범죄·아이디어·자발적·법칙`(2등급×L6, 4건) 등 **명백히 추상적·
학술적 어휘**가 다수였다. "습득 시기 등급"(공식 목록의 축)과 "학술적
추상도"(현재 DB L4~L6 배치가 실제로 반영하는 축)가 서로 다른 기준이라,
1레벨 차이 패턴과 같은 방식으로 일괄 적용하면 위험하다고 판단해 개별
검토로 돌렸다.

**규칙 커버리지**: 2개 규칙이 1,408/1,408건(100%) 커버 — 잔여
(`RESIDUAL_NO_RULE`) **0건**. **1,997건을 한 건씩 사람이 볼 필요는
없다** — 823건(개별 검토 필요, 뜻풀이 포함 상세 CSV 제공)만 보면 된다.

## 7. Dry-run 영향도 (계산만, 미적용)

### (a) 기존 문항 출제(SOURCE_VERSION=2.1.29) 영향

Rule A·B(1,408건, 안전 판정)를 **가상으로** 적용했을 때 레벨 연결이
확인되는 2.1.29 문항 1,114건의 레벨별 분포 변화:

| 레벨 | BEFORE | AFTER | 변화 |
|---|---:|---:|---:|
| L0 | 121 | 121 | +0 |
| L1 | 316 | 324 | +8 |
| L2 | 332 | 597 | **+265** |
| L3 | 337 | 64 | **−273** |
| L4 | 8 | 8 | +0 |
| L5 | 0 | 0 | +0 |
| L6 | 0 | 0 | +0 |
| 합계 | 1,114 | 1,114 | — |

**281건(전체의 25%)의 레벨이 바뀐다.** 가장 큰 영향은 L3 출제 풀이
337→64건으로 **81% 축소**되고 L2 풀이 332→597건으로 거의 두 배가 되는
것 — 이는 일괄 규칙이 안전하다는 재확인이면서 동시에, 실제 적용 시
L3 레벨 출제 가용량이 급격히 줄어든다는 뜻이라 **적용 전 L3 풀 축소에
대한 별도 대응 검토가 필요하다**(이번 범위 밖, 실제 적용 여부는 사람
승인 이후 결정).

## 결론

- 원본 집계 자체(5,950/5,829/227/2,182)는 재검증으로 전부 정확함이
  재확인됐고, 실제로 찾아 고친 누락은 §4 서술의 1건짜리 설명 공백뿐이다.
- 1,997건은 "기본_레벨_조정_후보"로 재분류했고, 4가지 예외(뜻풀이위험·
  동형이의·전문분야·레벨격차과대) 823건을 개별 검토로 뺀 뒤 **남은
  1,408건은 단 2개의 규칙(RULE_A/RULE_B)으로 100% 커버**된다 — 1,997건
  전체를 한 건씩 볼 필요가 없다.
- Dry-run 결과 L3 출제 풀 81% 축소·L0~L3 미리보기 매니페스트 40건 영향
  등 실제 적용 시 파급 효과가 작지 않음을 확인했다 — **이번 단계는
  계산만 했을 뿐, DB·레벨·문항·매니페스트 어느 것도 변경하지 않았다.**
- `review_status`는 전부 기계 제안이며 승인/레벨수정/보류는 사람이
  아직 아무것도 표시하지 않았다.
