# vocab_transition_approval_options_20261007

- 목적: 실제 DB/서비스 변경 전 대표님 승인 선택지를 3개 이하로 압축
- 전제: 현재까지 DB writes 0, deployment none. 아래 선택은 승인 요청안이며, 아직 실제 적용 승인으로 간주하지 않는다.

## 대표님 선택안

### 옵션 1 — 보수적 연결 우선

승인 범위:

- RULE_A 1,368건: 보류
- RULE_B 40건: 보류
- L3 보강: 64콘텐츠·128문항만 일반 L3 관리자 출제 후보로 연결 준비/적용 승인
- L3 보강 `level_status`: `REVIEW_BOUNDARY` 권장
- 벨기에 제외 유지
- batch2 미개별승인 3건(수시·숙련·순서도)은 추가 개별검토 전까지 제외

장점:

- 기존 레벨 정책 대량 전환 없이 L3 공급량을 회복한다.
- 사람 개별승인과 현재 매니페스트 기준이 가장 분명하다.
- RULE_A/B 정책 리스크와 보강 연결 리스크를 분리한다.

주의:

- L3 레벨 정책 전환은 지연된다.
- auto_only에 보강을 넣으려면 `PROVISIONAL_AUTO` 선택이 필요하므로 `REVIEW_BOUNDARY` 선택 시 auto_only 공급량은 기대만큼 늘지 않는다.

승인 문구 예시:

`옵션 1을 승인합니다. L3 보강 승인분 64콘텐츠·128문항만 일반 L3 관리자 출제 후보로 연결하고, 벨기에는 제외하며, batch2 미개별승인 3건은 보류합니다. level_status는 REVIEW_BOUNDARY로 합니다. DB 백업, 대상 ID 고정, 격리 리허설, 단일 트랜잭션 적용, 사후 검증까지 포함하며 RULE_A/B 적용, 학생 공개/allowlist/feature flag/배포는 승인하지 않습니다.`

### 옵션 2 — 정책 전환과 안전 보강 동시 준비

승인 범위:

- RULE_A 1,368건: L3 -> L2 적용 승인
- RULE_B 40건: L2 -> L1 적용 승인
- L3 보강: 64콘텐츠·128문항 연결 승인
- L3 보강 `level_status`: 대표님이 `REVIEW_BOUNDARY` 또는 `PROVISIONAL_AUTO` 중 선택
- 벨기에 제외 유지
- batch2 미개별승인 3건은 보류

장점:

- 공식 등급 기반 전환과 L3 공급 보강을 한 번의 실행 계획으로 정리한다.
- RULE_A/B 후 L3 공급 감소를 보강 64 연결로 일부 보완한다.
- 각 실행 단위는 manifest와 검증표를 분리해 원인 추적 가능하다.

주의:

- RULE_A/B는 총 1,408건의 대량 레벨 변경이므로 교육정책 승인 성격이 강하다.
- RULE_A/B 적용 후 L3 all_candidates는 보강 64를 연결해도 첫 정합성 보고 기준 75어휘·170문항 수준으로 예상된다.
- 실제 학생 공개나 배포는 이 옵션에도 포함되지 않는다.

승인 문구 예시:

`옵션 2를 승인합니다. RULE_A 1,368건은 L3에서 L2로, RULE_B 40건은 L2에서 L1로 연구 DB에 일괄 적용하고, L3 보강 승인분 64콘텐츠·128문항을 일반 L3 관리자 출제 후보로 연결합니다. 벨기에는 제외하고 batch2 미개별승인 3건은 보류합니다. L3 보강 level_status는 [REVIEW_BOUNDARY 또는 PROVISIONAL_AUTO]로 합니다. DB 백업, 대상 ID 고정, 격리 리허설, 단일 트랜잭션 적용, 사후 검증까지 포함하며 학생 공개/allowlist/feature flag/배포는 승인하지 않습니다.`

### 옵션 3 — 실행 보류, 추가 검토만 진행

승인 범위:

- RULE_A/B 실제 적용 보류
- L3 보강 레벨행 INSERT 보류
- DB 쓰기/배포/학생 공개 계속 금지
- 추가로 허용할 수 있는 작업은 읽기 전용 상세 검토, 격리 DB 리허설 스크립트 작성, whitelist 파일 초안 작성, 승인 전 체크리스트 보강까지만

장점:

- 실제 데이터 변경 위험이 없다.
- `level_status`, 64/67 연결 범위, RULE_A/B 정책 근거를 더 검토할 수 있다.

주의:

- 일반 L3 관리자 출제 공급량 문제는 해결되지 않는다.
- 실행 준비 상태에서 다음 승인 대기 상태가 이어진다.

승인 문구 예시:

`옵션 3을 선택합니다. RULE_A/B 적용과 L3 보강 연결은 보류하고, DB 쓰기·배포·학생 공개 없이 읽기 전용 상세 검토와 격리 리허설 스크립트 준비까지만 계속 진행하십시오.`

## Davinci 권장안

현재 단계의 권장안은 옵션 1이다.

이유:

- 대표 승인 없이 할 수 있는 준비는 완료되었고, 실제 변경은 승인 경계에 걸린다.
- RULE_A/B 1,408건은 교육정책 대량 전환이므로 별도 판단이 필요하다.
- L3 보강 64건은 사람 개별승인과 현재 매니페스트 기준이 가장 명확해, L3 관리자 출제 공급 회복을 위한 첫 실제 적용 단위로 가장 안전하다.
- 다만 auto_only 포함 여부가 중요하면 `level_status`를 별도로 명확히 선택해야 한다.
