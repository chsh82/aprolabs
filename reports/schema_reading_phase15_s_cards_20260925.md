# S(교과개념어) 검수 카드 — phase15 감사

**주의: 자동 검사 통과 ≠ 전문가 검수 완료.** 이 카드들은 literacy.db 원문과
결과표 간의 구조적 일치(표제어/정의 문자열/교과·주차 메타데이터)만 자동으로
확인한 것이며, 과학·사회 교과 내용의 정확성/적절성에 대한 전문가 검수를
대신하지 않는다. 모든 카드에 "전문가 검수 필요"가 표시된 이유다.
