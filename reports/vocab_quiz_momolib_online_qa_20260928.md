# momolib 어휘 퀴즈 관리자 전용 이식 — 온라인 검수(실사용) 완료

- 일자: 2026-09-28
- 방법: 운영 사이트(momolib.com)에 QA 임시 계정으로 실제 로그인해 관리자
  화면에서 L4·L5 40문항 / L6 40문항을 **실제로 응시**, 227건 콘텐츠를
  export 패키지·운영 DB 값과 **자동 전수 대조**, 4개 역할의 접근 차단을
  실제 HTTP 요청으로 확인.

## 1. 80문항 실제 응시 결과

| 파일럿 | 응시 결과 | 문항 표시 | 선택·즉시채점 | 완료화면 | 해설 |
|---|---|---|---|---|---|
| L4·L5(40문항) | **40/40** | 정상 | 정상(라디오 클릭 → 즉시 정답/오답 표시) | 정상(점수·완료시각) | 결과 화면에 문항별 해설 표시 |
| L6(40문항) | **40/40** | 정상 | 정상 | 정상 | 동일 |

- 제출 전 HTML/네트워크 응답에 `correct_option`/`answer_payload_json`
  **0건** 검출(정답 비노출 확인, 응시 화면 HTML 직접 스캔).
- `POST .../answer` 응답은 제출한 그 문항의 `is_correct`/`correct_option`/
  `explanation`만 포함(코드 리뷰로 재확인, `app/vocab_quiz/routes.py:227-233`).
- **UI 구조상 특이사항(버그 아님, 기존 설계)**: 파일럿 응시 화면은
  "다음 문항으로 이동"하는 1문항씩 넘기는 방식이 아니라 40문항이 한
  페이지에 스크롤로 모두 표시되는 구조입니다. 문항별 해설은 응시
  중에는 표시되지 않고(정답/오답 표시만) 완료 후 결과 화면에서만
  보입니다. 기존 구현 의도대로 동작 중이라 코드 수정하지 않았습니다.
- 정답 채점 정합성: 80문항 전부 사전에 제가 사전 판단한 "객관적으로
  옳은 선택지"를 골라 제출했고, 전부 "정답" 처리됨 — DB의
  `correct_option`이 실제 정의·문맥과 어긋나는 항목은 발견되지
  않았습니다.

## 2. 227건 전수 자동 대조 (export 패키지 vs 운영 DB)

읽기 전용 감사 스크립트로 `contents.json`(227)/`content_levels.json`
(227)/`pilot_l4l5_manifest_v1.json`(40)/`pilot_l6_manifest_v1.json`(40)을
운영 DB 현재 값과 전 필드(표제어·뜻풀이·예문·source_version·레벨상태·
boundary_flag·student_exposure·public_ready 등) 대조:

```
export 파일 건수: contents=227, levels=227, l4l5=40, l6=40
DB 건수: contents=227, levels=227, l4l5=40, l6=40
총 불일치: 0건
student_exposure 또는 public_ready = True 인 콘텐츠: 0건 (기대값 0)
boundary_flag=True 레벨(REVIEW_BOUNDARY): 227건
```

- **불일치 0건** — 표제어·뜻풀이·예문·정답·해설·source_version·비공개
  플래그 전부 export 패키지와 동일.
- `boundary_flag`(REVIEW_BOUNDARY) 227건 전체가 여전히 `True` —
  이관 이전부터 "학년 경계 미확정" 상태였던 것이 그대로 유지된
  것으로, 이번 검수에서 새로 발생한 문제가 아닙니다(4절 HOLD 참고).
- 한글 조사(은/는·이라는/라는·을/를) 오류를 받침 유무 규칙으로
  80문항 explanation 전수 기계 검사 → **1건** 발견(3절).

## 3. 접근제어 확인 (실제 HTTP)

| 대상 | `/vocab-quiz/` | `/vocab-quiz/contents` | `/vocab-quiz/pilot/l4l5` |
|---|---|---|---|
| 비로그인 | 302 → `/auth/login` | 302 | 302 |
| teacher | 403 | 403 | 403 |
| parent | 403 | 403 | 403 |
| student | 403 | 403 | 403 |
| super_admin(QA) | 200 | 200 | 200 |

전 9개 라우트가 동일한 `@login_required + @requires_role('super_admin',
'hq_manager')` 데코레이터를 쓰는 것을 코드로 재확인했고(`app/vocab_quiz/
routes.py`), 대표 3개 엔드포인트 × 4개 신원(비로그인/teacher/parent/
student)의 실제 라이브 요청 결과는 위 표와 같이 전부 예상대로
차단됩니다.

## 4. 발견한 문제

### 4-1. 조사 오류 1건 (콘텐츠 데이터, 표기 문제 — 수정하지 않음)

- **item_id**: `MF_A_SC_SRL4L5PILOT_20260925_L4_003` (L4·L5 파일럿,
  표제어 '집단', source_version=`schema_reading_literacy_l4_manual_v1`)
- 현재 텍스트: `"'집단'은 '여러 사람이 모여 이룬 무리'이라는 뜻입니다."`
- 문제: '무리'는 받침 없는 명사이므로 '이라는'이 아니라 **'라는'**이
  맞습니다 → `"...무리'라는 뜻입니다."`
- 동일 문항의 문장형 버전(`MF_C_SC_..._003`)은 다른 템플릿("...을/를
  뜻합니다")을 써서 이 문제가 없습니다.
- 80문항 전수 기계 검사에서 이 1건 외 조사 오류는 발견되지 않았습니다.
- **콘텐츠 텍스트는 지시에 따라 자동 수정하지 않았습니다.** 전문가
  검수·수정 대상으로 남겨둡니다.

### 4-2. 모바일 화면 — 상단 네비게이션 가로 스크롤(사이트 전역 이슈, 이번 범위 밖)

- 390px 폭에서 확인 결과, 어휘 퀴즈 화면 자체(문항 카드·선택지·결과
  카드)는 잘 접혀 정상 표시되지만, **모든 페이지 공통 상단
  네비게이션 바**(`base.html`)가 좁은 화면에서 줄바꿈되어 링크 글자가
  세로로 끊겨 보이고 약 46px의 가로 스크롤이 발생합니다
  (`document.documentElement.scrollWidth=531` vs `clientWidth=485`).
- 이는 어휘 퀴즈 전용 템플릿이 아니라 momolib 전체가 공유하는
  `base.html` 네비게이션의 기존 설계(반응형 햄버거 메뉴 없음) 때문이며,
  이번 관리자 전용 이식 범위 밖의 사이트 전역 이슈입니다. 관련 없는
  전역 템플릿을 임의로 고치는 것은 지시 범위를 벗어난다고 판단해
  **수정하지 않았습니다.** 참고로만 기록합니다.
