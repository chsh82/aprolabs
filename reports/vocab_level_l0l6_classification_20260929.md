# L0~L6 어휘 레벨 1차 자동 분류기 + 검수표

- 일자: 2026-09-29
- 범위: **연구 DB 전수(5,950건, 읽기 전용)**. DB 쓰기·레벨/문항 변경·빈 뜻풀이 생성·
  학생 공개·momolib 작업 전혀 없음. 연구 DB는 로컬로 읽기 전용 사본을 내려받아
  분석했고(운영 DB 직접 접속 없음), 산출물만 로컬 커밋(push 안 함).
- 산출 스크립트: `scripts/vocab/l0l6_parse_krdict.py`(KRDict 인덱싱),
  `scripts/vocab/l0l6_derive_boundary_207.py`(207건 재도출),
  `scripts/vocab/l0l6_build_classification.py`(본 분류기).

## 0. 핵심 설계 원칙

1. **기존 DB `vocab_level`은 추천 계산에 전혀 사용하지 않았다** — 사후 비교표(2절
   산출물)에만 등장한다.
2. **1차 근거는 DB에 이미 보존된 `nikl_vocabulary_grade`(국립국어원 어휘 등급)다.**
   이 값은 `vocabulary_content_levels.level_reason_json` 안에 문항(콘텐츠)별로
   남아 있으며, `docs/vocabulary/LEVEL_POLICY_v0.1.md`에 명시된 원천 정책
   (2등급→L0 중심, 3등급→L1~L2, 4등급→L3~L4, 5등급 이상 자료 없음)을 그대로
   따랐다. **2등급 같은 단일 밴드만 특정 레벨로 추천했고, 3등급/4등급처럼
   정책상 두 레벨에 걸치는 경우는 강제로 나누지 않고 "경계"로만 표시했다**
   (사용자가 예시로 든 "중1~3을 L3/L4로 자동 분할하지 말라"는 원칙을 이 프로젝트의
   실제 등급 체계에 그대로 적용한 것).
3. **L5·L6은 원천에 해당 등급 자료 자체가 없으므로 절대 추천하지 않았다**(정책
   문서 4절의 기존 한계와 동일). 대신 `227건`은 기존에 이미 별도 수동 근거
   (`MANUAL_LITERACY_L4/L5/L6_MATCH` — phase30~35 근거기반 집필 파이프라인의
   교재 대조 결과)로 확정된 것을 확인했고, 이번 자동분류는 **이 227건을
   재판정하지 않고 범위 밖으로 명시적으로 제외**했다(사후비교표에는 그대로
   "제외" 표시로 남긴다).
4. **표제어만 같다고 뜻풀이 일치로 보지 않았다** — KRDict(한국어기초사전) 대조는
   표제어가 같은 모든 동형이의 항목의 definition을 모아, DB 뜻풀이와 문자
   bigram Jaccard 유사도(임계값 0.30, 경험적)를 계산해 "뜻풀이까지 일치"할
   때만 그렇게 표시했다. 임계값 미만은 "표제어만 일치"로만 기록한다.

## 1. 외부 근거 확보 현황 — 무엇을 찾았고 무엇을 못 찾았나

| 근거 | 확보 여부 | 비고 |
|---|---|---|
| **국립국어원 어휘 등급(NIKL grade)** | **확보(로컬 DB 내 보존)** | `nikl_vocabulary_grade`(2~4등급), 5,723건. 원출처 CSV(`data/import/vocabulary_levels_v0.1.csv`)는 로컬 인코딩 손상이 있어 **라이브 DB의 `level_reason_json`에서 직접 재추출**했다(더 신뢰할 수 있는 경로). |
| **국립국어원 학년군별(초1-2/3-4/5-6/중1-3/고1-3) 구조화 어휘 목록** | **찾지 못함** | 리포지토리 전체(`docs/`, `raw/`, `app/`, `scripts/`)를 검색했으나 그런 형태의 파일은 없다. 이 프로젝트가 실제로 확보한 건 김광해 계열·NIKL 등급(2~4등급, 3단계)이지, 사용자가 언급한 "중1~3" 같은 학년군 표기의 별도 자료가 아니다 — **찾을 수 없는 자료를 지어내지 않았다.** |
| **KRDict(한국어기초사전) 초급/중급/고급** | **확보(로컬 raw 덤프, `raw/krdict/krdict_dump/`)** | 56,555개 항목, 51,909개 고유 표제어 인덱싱. **주의: 이 등급은 한국어를 배우는 외국인 학습자 기준이지 한국 초중고 교육과정 기준이 아니다**(`docs/literacy/00-현황.md` 243행에 이미 이 경고가 기록돼 있었다) — 그래서 이번 분류의 **보조(대조용) 근거로만** 썼고, 주 추천 레벨을 결정하지 않았다. |

**결론**: "국립국어원 기초 어휘 등급"에 해당하는 자료는 이미 이 DB 안에 있었다
(`nikl_vocabulary_grade`) — 새로 구해야 하는 게 아니라 이미 있는 걸 처음으로
"기존 vocab_level과 분리해서" 독립적으로 다시 적용한 것이 이번 작업의 핵심이다.

## 5. 기존 DB와의 충돌 건수 (사후 비교, 5절이 유일하게 기존 레벨을 쓰는 절)

| 비교 플래그 | 건수 | 의미 |
|---|---:|---|
| `DB_OVERCONFIDENT_BOUNDARY` | 2,993 | 내 근거로는 두 밴드에 걸친 "경계"인데, 기존 DB는 `PROVISIONAL_AUTO`로 특정 레벨 하나를 이미 확정해 둔 상태 — **원천 등급의 모호성을 기존 결정론적 규칙이 보조 특징(전문분야·뜻풀이 길이 등)으로 강제 해소한 결과로 보인다.** 오류라기보다 "재검토 우선순위가 높다"는 신호. |
| `BOUNDARY_DB_ALSO_BOUNDARY` | 2,117 | 내 근거도 경계, 기존 DB도 `REVIEW_BOUNDARY` — 서로 일치(이미 경계로 알려져 있었음). |
| `MATCH` | 612 | 추천(L0)과 기존 DB `vocab_level`이 정확히 일치. |
| `OUT_OF_SCOPE` | 227 | 수동 교재 근거 확정군(4절 참고) — 비교 대상 아님. |
| `CONFLICT` | **1** | 추천(L0)과 기존 DB(L1)가 실제로 불일치 — 아래 사례. |

**유일한 명시적 CONFLICT 사례**: `SC_V192_B002_030`(표제어 "고등학교") — NIKL
2등급 근거로 L0을 추천했으나 기존 DB는 L1(`PROVISIONAL_AUTO`)로 돼 있다. 표제어
자체가 상급 학교 개념을 담고 있어 원천 등급만으로는 부적절할 수 있는 대표적
사례 — 사람 판정 우선 권장.

## 6. 사람이 실제로 봐야 할 건수 — 뜻풀이 검토 대상(78건)

**"경계" 판정 자체는 검토 대상에 넣지 않았다** — 정책상 정상적인 1차 산출물이기
때문이다(사용자 지시: 뜻풀이 검토는 충돌·동형이의·고위험에만). 아래 세 가지
기준에 해당하는 78건만 `뜻풀이_검토대상=예`로 표시했다.

| 사유 | 건수 |
|---|---:|
| NIKL 2등급(L0 근거) vs KRDict "고급" 방향성 상충 | 73 |
| KRDict 동형이의 항목 간 등급 상이(동형이의 위험) | 4 |
| 기존 DB와 명시적 `CONFLICT`("고등학교") | 1 |
| **합계** | **78** |

이 78건은 **207∪17 우선순위 집합(132건)과 겹치지 않는다** — 두 목록은 서로
다른 위험축이다: 207∪17은 "출제와 가깝거나 레벨 자체가 미확정"인 **레벨
우선순위** 목록이고, 78건은 "뜻풀이 근거가 서로 어긋나는" **정의 신뢰도**
목록이다. 132건이 0건 겹친다고 해서 132건이 안전하다는 뜻은 아니며, 둘 다
별도로 검토가 필요하다.

## 7. 우선순위 검토 목록 (207∪17, 중복 제거 132건)

- 207건(레벨보류, 문항 품질은 통과했지만 `REVIEW_BOUNDARY`) → 고유 어휘
  **115개** (`scripts/vocab/audit_existing_l0l3_reusable_328.py`와 동일한
  검사 로직을 독립 재적용해 레벨별 4/34/159/10=207건을 정확히 재현·검증했다).
- L2 `PROVISIONAL_AUTO`(경계 아님, 자동승인 상태) → **17개**
  (`data/vocab/existing_l0l3_manifest_v1.json`의 L2 34건 문항이 딛고 있는
  고유 어휘).
- **두 집합의 교집합은 0건**이었다(레벨 상태 정의상 `REVIEW_BOUNDARY`와
  `PROVISIONAL_AUTO`는 상호 배타적이므로 구조적으로 당연한 결과지만, 가정하지
  않고 실제로 대조해 확인했다). 합집합은 115+17=**132건**.

## 8. 한계 및 다음 단계 제안(이번 범위 아님)

- bigram Jaccard는 형태소 분석기 없이 쓸 수 있는 최소 근거이며, 짧은 뜻풀이
  일수록 우연히 임계값을 넘거나 못 넘길 수 있다 — 정밀 임계값 튜닝은 사람
  검수 표본으로 재보정 권장.
- KRDict 등급은 외국어 학습자 기준이라 방향성 상충(73건)이 전부 실제 오류는
  아닐 수 있다 — 사람 판정 칸에서 개별 확인 필요.
- 3등급/4등급 "경계" 5,110건 전체를 사람이 한 번에 볼 수는 없으므로, 위
  132건(레벨 우선순위) + 78건(뜻풀이 우선순위) = **최대 210건**을 1차 검수
  대상으로 제안한다(중복 없음, 132+78=210).
