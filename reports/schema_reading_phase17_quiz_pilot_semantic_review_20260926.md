## 3. 통과 문항 근거 요약 (왜 오답이 확실히 틀렸는가)

### 3-1. 오답의 "다른 뜻" 가능성 점검 (동형이의/다의어)

20개 표제어 각각에 대해 국어사전상 알려진 다른 의미가 있는지 확인했다.

| 확인된 다의어/동형이의 후보 | 검토 결과 |
|---|---|
| 정기(定期) vs 정기(精氣, 기운) | 이번 배치 4지선다 옵션에 '정기(精氣)'의 뜻을 나타내는 선택지가 아예 없음(공간·집단·하위·정해진 기간뿐) + 문맥(매달 반복되는 모임)이 '정해진 기간' 의미로만 해석됨 → 정답 흔들림 없음 |
| 종속(從屬, 종속절/종속변수 포함) | 모두 같은 핵심 의미(딸려 붙음) → 오답과 겹치지 않음 |
| 합성(合成, 합성어/합성수 포함) | 모두 같은 핵심 의미(합쳐 하나를 이룸) → 오답과 겹치지 않음 |
| 공간(空間, 물리적/수학적 공간) | 모두 같은 핵심 의미(자리/영역) → 오답과 겹치지 않음 |
| 국면(局面, 바둑의 국면 포함) | 모두 같은 핵심 의미(상황/형편) → 오답과 겹치지 않음 |
| 나머지 15개 표제어(착수·조치·집단·하위·중복·간과·대등·본론·논술·부가·가치관·간략·감안·계승·급진) | 국어사전상 사실상 단일 의미 → 오답과 겹칠 여지 자체가 없음 |

결론: **40건 중 어느 오답도 목표어의 실제 다른 뜻과 우연히 일치하지
않는다.** 오답이 전부 "완전히 다른 개념(다른 표제어)의 정의"이기 때문에,
학생이 착각할 수 있는 지점은 "이 오답이 사실 목표어의 또 다른 뜻 아닌가"가
아니라 "이 오답이 그냥 다른 낱말의 뜻이라는 걸 알아채는가"이며, 이는
정의 문장 자체가 명백히 다른 개념(예: 착수 vs 집단)이라 혼동 가능성이
낮다.

### 3-2. CONTEXT_MEANING 예문의 문맥 배제력

20개 예문 전부에서, 문맥이 정답 정의로만 자연스럽게 읽히고 나머지 3개
오답 정의는 문장에 대입되지 않음을 확인했다. 특히 아래 4건은 대비/인과
관계로 배제력이 더 뚜렷하다.

- **종속**: "본부에 종속되어 중요한 일을 혼자 결정할 수 없습니다" —
  "하위"(등급 낮음)와 개념적으로 가까워 보일 수 있으나, "혼자 결정할 수
  없다"는 결과절이 "자주성 없음"(종속)만 지지하고 "등급이 낮다"(하위)는
  지지하지 않는다.
- **합성**: "여러 사진을 합성하여 새로운 장면을 만들었습니다" —
  "중복"(반복/겹침)과 개념적으로 근접해 보일 수 있으나, "새로운 장면을
  만들었다"는 결과절이 "합쳐서 새 것을 만듦"(합성)만 지지한다.
- **간과**: "안전 규칙을 간과해서 작은 사고가 났습니다" — 인과관계가
  "대충 보아 넘김"만 지지.
- **급진**: "천천히 바꾸기보다 급진적인 개혁을 주장했다" — "천천히"와의
  명시적 대비가 "서둘러 급히 나아감"만 지지.

나머지 16건도 동일한 방식으로 확인했으며 상세 근거는 결과표
`semantic_reason` 컬럼(문항별 `[정답 유일성]`/`[문맥형 추가확인]` 구획)에
전부 기록했다.

### 3-3. `explanation` ↔ `literacy.db` 정의 일치 확인

20개 표제어 전부 DB를 `mode=ro`로 재조회해 대조한 결과, 19개는 표현만
다르고 의미가 완전히 동일했다(예: '착수' explanation "어떤 일을 시작하여
손을 대는 것" = DB "어떤 일에 손을 댐. 또는 어떤 일을 시작함."). **1건
('정기')은 아래와 같이 미세한 해석 차이가 있어 별도 기록한다.**

> **'정기' 주의 사항 (SEMANTIC_PASS 유지, 사유 명시)**
> - DB 원문: `기한이나 기간이 일정하게 정하여져 있는 것. 또는 그 기한이나
>   기간.`
> - phase16 explanation/정답 옵션: `일정한 기간마다 되풀이하도록 정한 것`
> - DB 원문은 "기간 자체가 고정되어 있다"는 뜻만 명시하고 "반복(되풀이)"을
>   직접 언급하지 않는 반면, phase16 문구는 "되풀이"라는 해석을 추가했다.
>   실제 용례(정기모임·정기국회·정기점검)가 모두 주기적 반복을 내포하므로
>   상식적으로 크게 틀린 해석은 아니지만, **DB 문언과 축자적으로 100%
>   일치하지는 않는다.**
> - 다만 이 차이가 정답 유일성이나 오답 배제에 영향을 주지 않는다(오답
>   3개는 공간·집단·하위로 '정기'와 전혀 무관한 개념이라, "되풀이" 유무와
>   무관하게 정답은 하나로 유지됨). 따라서 **HOLD로 내리지 않고
>   SEMANTIC_PASS로 유지**하되, 문언 정밀도 개선을 원하면 아래 수정안을
>   참고할 것(4절 참고, 강제 수정 아님).

나머지 19개 표제어는 이런 해석 확장 없이 DB 원문과 축자적으로도 가까운
수준으로 일치했다(결과표 `semantic_reason`의 `[해설-DB 일치]` 구획에
DB 원문을 그대로 인용해 대조 가능하게 해 두었다).

## 7. 가장 중요한 리스크

1. **HOLD 0건이 "검토가 느슨했다"는 뜻이 아니라 "오답 생성 전략이 원천적으로
   안전하게 설계됐다"는 뜻**이라는 점을 분명히 해야 한다 — 오답이 매번
   완전히 다른 표제어의 실제 정의에서만 나오므로(무작위 생성이 아님), 이번
   20개 표제어 조합에서는 의미적 충돌이 나타나지 않았다. 다만 이는 **이번
   특정 20개 조합에 한정된 결론**이며, 표제어 풀이 커지거나(S 항목 포함
   등) 서로 의미가 가까운 표제어끼리 짝지어지는 경우(예: 유의어·상하위어
   관계 표제어가 같은 배치에 들어가는 경우)에는 이번과 다른 결과가 나올 수
   있다 — 다음 파일럿(특히 S 항목 포함 시)에서 반드시 재검증 필요.
2. '정기' 문항의 explanation이 DB 원문에 없는 "되풀이" 뉘앙스를 추가한
   점은 기능적 결함은 아니지만, 이런 "쉬운 말 재정의가 DB 원문에서 미묘하게
   벗어나는 패턴"이 다른 표제어/다른 배치에서도 반복될 수 있으므로, 향후
   대량 생성 시 `explanation` 자동 생성 로직에 "DB 원문에 없는 새 개념
   추가 금지" 같은 체크를 넣는 것을 고려할 만하다.
3. 이번 검토는 전적으로 검토자(에이전트)의 국어 지식에 의존한 수작업
   판정이다 — 표준국어대사전 등 외부 사전 API/DB로 교차 검증하지는
   않았으므로, 실제 배포 전 최종 단계에서는 사람 전문가의 확인이 여전히
   권장된다(phase16 보고서의 "전문가 검수 완료 아님" 표시와 일관).
